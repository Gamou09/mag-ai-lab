# mag-ai-lab

My hands-on lab for Generative AI and agents: Claude Code skills, MCP servers, subagents and other experiments, built while learning.

## What's inside

| Folder | What it is |
|---|---|
| [CLAUDE-CODE-SKILLS](CLAUDE-CODE-SKILLS/) | Writing Claude Code skills (`SKILL.md`, scripts, references) |
| [MCP-SERVER](MCP-SERVER/) | A Python MCP server that exposes a US weather forecast tool (NWS API) |
| [expense-tracker](expense-tracker/) | A command-line expense tracker in plain Python |
| [subagents](subagents/) | Claude Code subagents (work in progress) |

Each folder is self-contained and has its own README with setup and run instructions.
